  <section class="atif-section">
    <h2>Dual-Mode NDJSON Pipeline</h2>
    <p class="atif-section-lead">
      Every ATIF v2.0 file starts with a line-1 <code>meta</code> record declaring <code>document_type</code>, unifying crash-safe harness logging with fast analytical reads under one <code>AtifRecord</code> line envelope.
    </p>
    <div class="atif-pipeline not-content">
      <div class="atif-stage">
        <div class="atif-stage__head">
          <h3>Runtime Events</h3>
          <code>.atif-e.jsonl</code>
        </div>
        <p>
          Append-only <code>event</code> and <code>extension</code> rows emitted 1:1 from live agent harnesses. Captures rewinds and retries via <code>EventBranch</code> jumps without buffering turns in memory.
        </p>
      </div>
      <div class="atif-stage__arrow" aria-hidden="true">→</div>
      <div class="atif-stage">
        <div class="atif-stage__head">
          <h3>3-Phase Consolidation</h3>
          <code>events → trajectories</code>
        </div>
        <p>
          Deterministic transform: <strong>1.</strong> linearizes the event DAG into trunk and off-trunk branches, <strong>2.</strong> folds <code>response_id</code> slices and action outputs, <strong>3.</strong> populates <code>step_id</code>, truncation previews, and rollups.
        </p>
      </div>
      <div class="atif-stage__arrow" aria-hidden="true">→</div>
      <div class="atif-stage">
        <div class="atif-stage__head">
          <h3>Consolidated Trajectories</h3>
          <code>.atif.jsonl</code>
        </div>
        <p>
          Contiguous <code>1..N</code> steps per trajectory, head-of-file <code>meta.manifest</code> for O(1) indexing, optional <code>.atif.tar.zst</code> blob archives, and 1:1 Protobuf and SQL projections.
        </p>
      </div>
    </div>
  </section>

  <section class="atif-section">
    <h2>Core Specification Design</h2>
    <div class="atif-pillars not-content">
      <article class="atif-pillar">
        <h3>Non-Linear Lineage &amp; Compaction</h3>
        <p>
          Subagents, session forks, Best-of-N candidates, and discarded rewinds serialize as flat sibling <code>trajectory</code> rows with <code>parent_*</code> pointers and Delta Mode prefix deduplication. Context summarization lives in-place on <code>Step.compaction</code>.
        </p>
        <a href="/spec/v2.0/#ndjson-records-sessions-trajectories--lineage">Lineage &amp; branching rules →</a>
      </article>

      <article class="atif-pillar">
        <h3>Colocated Actions &amp; Canonical Normalization</h3>
        <p>
          <code>Step.actions[]</code> collocates raw tool arguments, multimodal outputs, timing, error state, approvals, and execution plane (<code>client</code>, <code>environment</code>, <code>provider</code>, <code>external</code>) alongside an optional typed <code>Action.canonical</code> overlay across 28 action kinds.
        </p>
        <a href="/spec/v2.0/references/canonical-actions/">Canonical Actions Catalog →</a>
      </article>

      <article class="atif-pillar">
        <h3>Content-Addressed Blobs &amp; Inline Previews</h3>
        <p>
          Oversized tool outputs, file diffs, and system prompts retain readable inline previews (16 KiB default) with local <code>truncated_fields</code> metadata and SHA-256 <code>BlobReference</code> URIs, keeping warehouse queries fast without 100 MB JSON trees.
        </p>
        <a href="/spec/v2.0/#inline-truncation-truncationinfo--content-addressed-blobs-blobreference">Truncation &amp; blob layout →</a>
      </article>

      <article class="atif-pillar">
        <h3>Schemas, Projections, &amp; Agent Discovery</h3>
        <p>
          Co-maintained JSON Schema 2020-12, <code>proto3</code> wire definitions, six normalized warehouse SQL tables, and a language-agnostic conformance suite. Every page on this site exposes a raw <code>.md</code> mirror and an HTTP-discoverable skill.
        </p>
        <a href="/spec/v2.0/references/projections/">Wire &amp; Warehouse Projections →</a>
      </article>
    </div>
